# AGENTS.md

## Project
This is an HTML/CSS/JS awards reveal deck for a live event.

## Priorities
1. Preserve the visual output unless explicitly asked to redesign.
2. Keep the source easy for a non-developer to edit.
3. Maintain a build/export path to a single standalone HTML file.
4. Do not rely on internet access for the final exported event-night file unless explicitly approved.
5. Keep animations performant on ordinary laptops.
6. Update the version number on every meaningful change.

## Distribution target
The final output should be a single HTML file that can be opened locally in Chrome or Edge.

## Editing model
Important editable content should live in clear data/config files rather than being buried in rendering code.

## Style
Premium black/gold awards-show aesthetic. Avoid cheap-looking confetti, cartoon stars, hard masks, or noisy over-animation.
